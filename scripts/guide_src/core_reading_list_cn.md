## 通读与查询的区分

- **通读**：教材与课程按章节顺序学，配套作业必须做。
- **查询**：官方文档、标准、手册（PostgreSQL、Python 标准库、GCC、CUDA Runtime API、RFC、OWASP 速查表等）在遇到具体问题时检索。每个工具的入门教程部分建议通读一遍，其余查询。
- **对照**：参考实现与示例源码，先自己写，再对照阅读。
