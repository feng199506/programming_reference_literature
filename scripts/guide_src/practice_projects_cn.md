- 本库只保存项目源码、说明和许可证，不执行来源代码，也不下载数据集与模型权重。动手时请在自己的隔离环境中按项目 README 安装依赖。

## 评价方式通用建议

1. **正确性**：优先用项目自带测试。没有测试时先写测试再实现。
2. **可复现**：固定依赖版本与随机种子，一条命令复现结果。
3. **性能**：报告基线、硬件、测量方法与多次运行的统计量。
4. **工程质量**：类型检查、lint、CI 全绿。README 写清运行方式与已知限制。
