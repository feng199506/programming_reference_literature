**测量驱动优化流程**（依据〔12B03〕〔12C01〕）：

1. 固定输入与环境，多次测量取统计量。
2. 先用剖析器找热点，再用硬件计数器判断瓶颈类型。
3. 一次只改一处，改完回归测量。
4. 记录基线与每次改动的收益。
