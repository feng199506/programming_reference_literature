# AI 编程学习路线：科学计算、机器学习、深度学习与实验管理

适合对象：已完成 `beginner_path_cn.md` 阶段 1–2（Python 基础与工程化），并具备线性代数、概率统计入门知识的学习者。
目标：能写出无数据泄漏的机器学习训练管线，能用 PyTorch 从张量写到分布式训练与混合精度，并能管理实验、数据版本与检查点。

工具版本均为 2026-10-29 时点的官方当前版本，详见 `../tools/tools_catalog_cn.csv`。

## 阶段 4：机器学习编程（约 6–8 周）

先修条件：阶段 1–3，概率统计。

| 5 | 〔04B03〕 | 数据集、基准与留出法的局限：理解评测偏差和泄漏 |
| 6 | 〔04D02〕、〔04D03〕、〔04D04〕 | 梯度提升三件套：XGBoost、LightGBM、CatBoost 的参数、类别特征、GPU、模型导出 |
| 示例 | 〔04X01〕、〔04X02〕、〔04X03〕、〔04X04〕 | 官方示例源码，学完一节就对照一个示例 |
| 查询 | 〔04B02〕 | 数学推导与 Python 代码并行的参考书 |

**数据切分与泄漏防范清单**（依据〔04C04〕〔04D01〕〔04B03〕）：

1. 先切分再拟合预处理器，预处理放入 Pipeline，在交叉验证内部拟合。
2. 时间序列用时间顺序切分，不打乱。分组数据用 GroupKFold。
3. 超参数搜索用嵌套交叉验证，或保留独立测试集。测试集只用一次。
4. 特征工程中的目标编码、缺失值填补、标准化都属于"拟合"，必须在训练折内完成。

## 阶段 5：深度学习编程（约 8–10 周）

先修条件：阶段 4，微积分、线性代数。

| 顺序 | 资料 | 用法 |
|---|---|---|
| 1 | 〔05X51〕 | 先手写一个标量自动微分引擎，理解反向传播 |
| 2 | 〔05B01〕 | 主教材（PyTorch 版）：张量 → 自动微分 → MLP/CNN/RNN/Transformer → 优化 → 计算性能 |
| 3 | 〔05D02〕 | PyTorch 官方教程：Learn the Basics → 自定义 Dataset/DataLoader → 保存加载 → 混合精度（AMP）→ 分布式入门 |
| 4 | 〔05D01〕 | PyTorch 2.15 文档：nn、optim、autograd、amp、checkpoint、torch.compile 页按需查询 |
| 5 | 〔05C01〕、〔05C03〕 | Stanford CS231n 讲义；UvA DL 教程笔记本（PyTorch/JAX，含多 GPU） |
| 6 | 〔05X52〕、〔05X03〕 | 从 makemore 到 GPT；nanoGPT 训练循环、AMP、DDP、检查点 |
| 7 | 〔05B02〕、〔05B03〕 | 原理补充与速查 |
| 8 | 〔05C02〕 | 进阶：自己实现深度学习框架（自动微分、GPU 后端） |
| 9 | 〔05C04〕 | MIT 6.S191 实验：PyTorch 与 TensorFlow 双版本对照 |

**训练循环调试清单**（依据〔05D02〕〔05B04〕〔05D01〕）：

1. 先在一个 batch 上过拟合，确认损失能降到接近 0。
2. 检查数据管线：打印样本与标签，确认归一化和数据增强正确。
3. 用 `torch.autograd.detect_anomaly` 与梯度范数监控定位 NaN 和梯度爆炸。
4. 混合精度用 autocast + GradScaler（fp16）或 bf16。检查点同时保存模型、优化器、调度器、随机数状态与 step。
